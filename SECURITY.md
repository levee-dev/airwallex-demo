# Security policy

Please report vulnerabilities privately to **security@levee.dev**, not in public issues or pull requests. Include what you found, how to reproduce it and the impact you expect. We aim to acknowledge reports within three working days and will keep you updated until a fix ships.

Acme Pay is reference code that runs only against the Airwallex and Levee sandboxes. Reports about how it handles credentials, sessions, passkeys, webhooks or agent authorization are especially welcome. Issues in Levee or Airwallex themselves can also go to security@levee.dev and we will route them.

Only the latest commit on `main` is supported.
